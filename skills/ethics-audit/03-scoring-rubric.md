# 03 — 採点ルーブリック

採点は **CLI（`lib/cli.js score`）が決定論的に**行う。本ドキュメントはその基準を人間・
エージェントに説明するもので、値の**正本は `lib/commands/score.js`**（`SEVERITY_PENALTY`,
`PRINCIPLE_WEIGHT`, 閾値）である。手計算で忖度せず、必ず CLI に集約させる。

## 入力は「確定所見」のみ
採点対象は `confirmed:true` の findings だけ。Step 2 の敵対的検証を通っていない指摘は
スコアに影響しない（grandstanding を採点に混ぜない）。

## 原則スコア（0–100・減点方式）
各原則は 100 点から、その原則に属する確定所見ごとに深刻度の減点を引く。0 で下げ止まる。

| 深刻度 | 減点 |
|--------|------|
| critical | 50 |
| high | 22 |
| medium | 9 |
| low | 3 |

所見の原則は項目ID先頭（例 `3.12` → 原則3）で決まる。

## 総合スコア（加重平均）
「公共の利益が中心」ゆえ原則1・3を重くする。重み合計は 1.00。

| 原則 | 重み |
|------|------|
| 1 公共性 | 0.22 |
| 2 顧客ならびに雇用者 | 0.10 |
| 3 製品 | 0.18 |
| 4 判断 | 0.12 |
| 5 管理 | 0.10 |
| 6 専門職 | 0.10 |
| 7 職業上の同僚 | 0.08 |
| 8 自己の向上 | 0.10 |

総合 = Σ(原則スコア × 重み)（四捨五入）。

## 判定（Verdict）
- **合格**: 総合 ≥ 80 **かつ** critical 所見が0件。
- **要改善**: 総合 ≥ 55（合格条件を満たさない場合）。
- **不適合**: 総合 < 55。

**critical が1件でもあれば「合格」は出ない**（総合が高くても最良で「要改善」）。これは
公共の安全・プライバシー・法令に直結する害を、点数の平均で薄めさせないための歯止め。

## 深刻度の判断基準（findings 側の指針）
- **critical**: 公共の安全・プライバシー・法令に直結する害。例: TLS/証明書検証の無効化、
  無同意の個人情報収集・送信、退会/削除の実質不能、秘密鍵の露出。
- **high**: 重大なユーザー不利益・誤認誘導・秘密情報のハードコード・個人情報のログ露出。
- **medium**: 手法・品質・テスト・文書化の重要な欠落、同意の擬制（事前チェック等）。
- **low**: 限定的・軽微な逸脱（空 catch など単発の握り潰し）。

迷ったら影響範囲（何人が・どれだけ不可逆に害されるか）と可視性（利用者が気づけるか）で
一段上げ下げする。過大評価も grandstanding の一形態であることに注意する。
